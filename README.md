# 陶艺非遗课程编排

面向“荣昌陶艺课程”的课程编排与作品流转服务。教务员发布揉泥/拉坯/修坯
分阶段课次，按安全容量（拉坯课还受陶轮工位约束）录入学生与具备阶段资质
的指导教师，维护候补队列与自动替补；每件作品记录从领泥到烧制的完整责任
交接链；临时停窑、教师时间冲突、重复签到都有明确的回滚/补课处理与审计，
学生只能查看本人被授权的作品。

## 目录

- `src/taoyi_course/domain.py` 阶段常量、作品/窑炉状态机、调用身份与领域异常。
- `src/taoyi_course/store.py` 线程安全 SQLite 存储；业务编排走 `BEGIN IMMEDIATE` 事务。
- `src/taoyi_course/service.py` 课程、报名候补、签到补课、作品流转、窑炉周转、授权与审计。
- `src/taoyi_course/api.py` JSON 请求适配，领域错误统一映射为错误信封。
- `tests/` 四个验收场景与护栏规则的可重复测试。

## 关键规则

- **并发报名**：容量计数与占位在同一立即事务内完成，满员自动进候补，退名额
  由候补队首替补（撤回同意时跳过已失同意的候补），绝不超卖。
- **监护同意**：报名/签到/领泥要求有效同意；撤回同意后已交出或入窑作品
  归属冻结、继续烧制，仍在学生手中的在制品归还学生；空出名额自动补位。
- **补课**：请假或整课取消发放“同阶段”补课额度，跨课次排入时核销；
  跨阶段、重复使用、排入满员课次均被拒绝且额度不核销。
- **窑炉**：停窑期间装窑/开烧被整体回滚（无半装批次）并留 `kiln.blocked`
  审计；窑内作品原样保留，恢复后状态连续，归属始终不变。
- **冲突与重复**：教师时间冲突、资质不符的安排整体回滚并留审计；重复签到
  拒绝覆盖，出勤记录不变并留 `session.checkin_duplicate` 审计。
- **授权**：学生/监护人只能查看本人名下作品；审计仅教务员可读。

## 运行

```
PYTHONPATH=src python3 -m unittest discover -s tests
python3 -m compileall src
```

项目只使用 Python 标准库。
