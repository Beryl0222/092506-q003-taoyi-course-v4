# 陶艺非遗课程编排

面向“荣昌小学陶艺课程”的课程编排与作品流转服务。服务把分阶段课次、报名候补、
监护同意、跨课次补课、作品责任交接和窑炉周转全部保存在本地 SQLite，
应用层通过进程内 JSON 适配器调用；只依赖 Python 标准库。

## 业务能力

- **分阶段课次**：揉泥 / 拉坯 / 修坯三个阶段；发布时校验教师阶段资质、教师时间冲突、
  人数安全容量，拉坯/修坯课次容量取“人数与陶轮数”的较小值。
- **报名与候补**：容量内直接占席，超额进入按顺位的候补队列；席位因请假/撤回释放时，
  同一事务内自动补位。全部写操作走 `BEGIN IMMEDIATE`，同课次并发报名不会超卖。
- **签到**：已占席且监护同意仍有效才能签到，重复签到被拒绝并返回冲突错误。
- **监护同意撤回**：学生退出所有未结束课次、释放席位并补位；
  已入窑/烧制中的作品归属与保管链保持不变，继续烧制与发还；预留的补课资格退回。
- **跨课次补课**：课次取消向已占席/已签到学生发放同阶段补课资格；
  资格校验阶段、只能本人使用、候补不预占、占席预留、签到核销、请假/撤回退回。
- **作品流转**：领泥 → 揉泥 → 拉坯 → 修坯 → 入窑 → 烧制 → 发还，
  禁止跳阶；每次交接记录保管人、责任人、课次/批次与时间，形成完整责任链。
- **窑炉周转**：批次装窑受窑容与“一件作品只能在一个在窑批次”约束；
  临时停窑时在窑批次挂起、作品状态/归属不变且禁止装窑烧制；恢复后批次回到
  停窑前状态继续烧制。
- **授权查看**：学生/监护人只能查看自己名下作品，教师只能查看经手作品，
  名单与审计仅教务员/任课教师可见。
- **审计**：所有关键动作写入 `audit_log`，可按实体按时间顺序回溯。

## 目录

- `src/taoyi_course/domain.py`：阶段、状态常量、业务错误类型。
- `src/taoyi_course/store.py`：SQLite 连接、表结构、事务边界。
- `src/taoyi_course/service.py`：课程编排与作品流转应用服务。
- `src/taoyi_course/api.py`：JSON 请求适配（成功 `{"ok": true, "data": ...}`，
  业务失败 `{"ok": false, "error": {"code", "message"}}`）。
- `tests/`：基线测试与验收测试（含多连接文件库的并发报名）。

## 运行

```bash
PYTHONPATH=src python3 -m unittest discover -s tests
python3 -m compileall src
```
